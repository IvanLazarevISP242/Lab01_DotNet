# ответы на вопросы
1. Console.Write() выводит без переноса строки, а Console.WriteLine() выводит с переносом строки
2. выдаст ошибку типа данных
3. C# дает 3, потому что происходит деление целых чисел. Для получения дробного результата 1 из цифр в примере должна быть с плавающей точкой
4. C# позволяет использовать var — компилятор сам определит тип переменной по значению. var не делает переменную «динамической» как в Python. Тип определяется один раз при объявлении и больше не меняется.
5. Язык C# и платформа .NET активно используются в крупных мировых компаниях и на масштабных проектах:
- Stack Overflow — один из крупнейших в мире сайтов с вопросами и ответами для программистов. Его бэкенд и веб-приложение написаны на ASP.NET MVC с использованием SQL Server, Redis и .NET Core, что обеспечивает высокую скорость работы при огромной посещаемости.
- Microsoft Azure — облачная платформа гигантского масштаба от Microsoft. Большинство её ключевых сервисов, бэкенд-компонентов, API и внутренних систем управления написаны на C# и ASP.NET / ASP.NET Core.
